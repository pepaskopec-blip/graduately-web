# Graduately Web

**English** · [Česky](#česky)

Promotional website and legal pages for **Graduately** (v1.3) — a Maturita exam preparation app for **macOS, Windows, Linux, Android, and iOS**.

- **Live site:** [graduately.skopec.dev](https://graduately.skopec.dev)
- **Installers & Releases:** [Graduately-releases](https://github.com/pepaskopec-blip/Graduately-releases)
- **Legal pages:** [Privacy Policy](https://graduately.skopec.dev/privacy.html) · [Terms of Use](https://graduately.skopec.dev/terms.html) · [EULA](https://graduately.skopec.dev/eula.html)

## Structure

- `index.html` — standalone static landing page (HTML + CSS) showcasing Graduately 1.3 (13 subjects, 625+ lessons, 82 reading-list books, GradAI tutor, daily streak, leaderboard, pricing, and downloads)
- `privacy.html` — bilingual Privacy Policy (CZ + EN)
- `terms.html` — bilingual Terms of Use (CZ + EN)
- `eula.html` — bilingual End User License Agreement (CZ + EN)
- `screenshots/` — Retina screenshots from Graduately 1.3 (`welcome-app.png`, `gradai-app.png`, `exam-app.png`, `leaderboard-app.png`, `books-app.png`, `german-app.png`)
- `favicon.svg`, `favicon.ico`, `favicon-*.png`, `apple-touch-icon.png`, `icon-*.png`, `site.webmanifest` — Graduately web icon suite & PWA manifest
