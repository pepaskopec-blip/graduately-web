# Graduately Web

Propagační web pro aplikaci **Graduately** — přípravu na maturitu pro macOS, Windows, Linux, Android a iOS.

Živá verze běží na [graduately.skopec.dev](https://graduately.skopec.dev), instalační balíčky a aktualizace jsou hostované na [Graduately-releases](https://github.com/pepaskopec-blip/Graduately-releases).

## Struktura

- `index.html` — samostatná statická stránka (HTML + CSS)
- `screenshots/` — aktuální náhledy aplikace
- `favicon.ico` — ikona webu
