# Graduately Web

Propagační web pro [Graduately](https://github.com/pepaskopec-blip/Graduately) — vzdělávací aplikaci k přípravě na maturitu.

## Spuštění

```bash
npm install
npm run dev
```

Otevři [http://localhost:3000](http://localhost:3000).

## Stack

- Next.js (App Router)
- React
- Tailwind CSS
- Glassmorphism UI
